# Memory Game — Memory Garden

Игра на развитие памяти: найдите 8 пар фруктов на поле из 16 карточек за наименьшее количество ходов.

## Возможности

- Случайное перемешивание карточек при загрузке и каждой новой игре.
- Счётчики ходов и найденных пар.
- Окно победы с итоговым результатом.
- Таблица 10 лучших результатов с сохранением в `localStorage`.
- Перезапуск игры без перезагрузки страницы.
- Адаптивная сетка 4 × 4 и управление с клавиатуры.

## Правила игры

1. Откройте две разные карточки — это один ход.
2. Совпавшие карточки остаются открытыми. Несовпавшие закрываются через секунду.
3. Найдите все 8 пар, чтобы завершить игру и сохранить результат.

**New Game** начинает новую игру, **Leaderboard** открывает таблицу лидеров.
Результаты сортируются по количеству ходов; при равенстве выше стоит более ранняя игра.
Сохранённые результаты доступны в том же браузере после перезагрузки страницы.

Для управления с клавиатуры используйте **Tab**, **Enter** или **Space**.
Модальные окна закрываются кнопкой **Close**, клавишей **Escape** или кликом по фону.

## Локальный запуск

Понадобятся Git, Node.js версии 22.12+ и npm.

```bash
git clone --branch memory-game https://github.com/Xelen/memory-game.git
cd memory-game
npm ci
npm run dev
```

Откройте в браузере адрес, который Vite выведет в терминале.

## Сборка и проверка

```bash
npm run build
npm run preview
```

- `npm run build` — production-сборка в папку `dist`.
- `npm run preview` — локальный просмотр готовой сборки по адресу из терминала.

## Технологии

HTML, CSS и JavaScript без UI-фреймворков. Vite используется для разработки и сборки.
Весь интерфейс создаётся через общий JavaScript-хелпер `createElement`.
Для карточек используются Unicode-эмодзи; их вид зависит от операционной системы.
